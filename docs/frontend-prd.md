# Frontend PRD — 场馆目录 Web 应用

> 状态基线:2026-10-02。本文档描述**当前已交付**的产品需求,非未来规划。

## 1. 产品概述

中文界面的场馆目录单页应用(React SPA):访客浏览 60 个体育场馆(足球场/篮球场/羽毛球场/网球场各 15),支持搜索、类型筛选、分页,点击卡片进入详情页;支持注册/登录账号。视觉采用「体育画报」复古杂志风(粗黑边框、黑体斜体大标题、橙蓝双色)。

## 2. 用户与场景

| 用户 | 场景 |
|---|---|
| 访客 | 浏览目录、按名称/城市搜索、按类型筛选、翻页与跳页,点卡片看详情 |
| 访客 | 在详情页查看开放时间/位置/客服电话(可点击拨号) |
| 注册用户 | 注册(即登录)、登录(带验证码)、记住登录状态 30 天、退出 |
| 所有用户 | 看到每张卡片上的「预订」入口(占位,功能后续开放) |

## 3. 功能需求(已交付)

### FR1 场馆目录

- 网格卡片(自适应列宽),每页 12 条,当前 60 条共 5 页
- **列表状态存于 URL**(`?q=&type=&page=`):链接可分享;进详情再返回,筛选结果精确还原

### FR2 搜索

- 输入即时生效,300ms 防抖;以 replace 写入 URL,不逐键堆积浏览器历史
- 匹配场馆名称与城市/位置;头部实时显示「命中 N VENUES」

### FR3 类型筛选

- 原生下拉(画报风样式),选项由后端类型接口驱动,随数据自动更新
- 选中项左侧色点跟随类型颜色;切换时回到第 1 页

### FR4 分页

- 首页/上一页/页码/下一页/末页;页数多时折叠为当前页 ±2 + 省略号
- 页码直达输入框(回车/失焦提交,自动夹取合法范围)

### FR5 场馆详情页(`/venues/:id`)

- 同源图片放大的整幅大图、类型徽标(色块)、编号
- 信息栅格:场馆类型/开放时间/场馆位置/客服电话(tel: 链接可拨号)
- 加载中/未找到(含返回首页)/加载失败(含重试)三态;页面标题随场馆名

### FR6 账号体系

- 右上角入口:访客见「登录」,登录后见用户名 +「退出」
- 弹窗内登录/注册切换:注册(用户名/邮箱/密码/确认密码,前端预校验与服务端同规则);登录(邮箱/密码/图形验证码/记住登录 30 天)
- 验证码:点击图片刷新;登录失败自动刷新(旧码已被消费)
- 刷新页面自动恢复登录态;token 失效自动清理

### FR7 预订入口(占位)

- 每张卡片右下角「预订」按钮,**本期无功能**:点击不触发跳转,为预订流程预留

### FR8 可访问性与体验

- 列表统计 `aria-live` 播报;分页当前页 `aria-current`;全站键盘焦点可见(focus-visible 描边)
- 缩略图懒加载;详情大图(LCP 元素)不懒加载;`prefers-reduced-motion` 下关闭装饰动画

## 4. 非功能需求(已满足)

- **响应式**:卡片网格 auto-fill(240px 起)随视口伸缩;详情信息栅格移动端单列
- **传输安全**:API 经同源代理走 HTTPS 后段(密码/token 不明文)
- **状态可恢复**:筛选/搜索/页码全在 URL;登录态跨刷新恢复

## 5. 边界与已知限制

| 限制 | 说明 |
|---|---|
| 预订未实现 | 按钮为纯占位,无任何业务行为 |
| 会话 token 不跨标签页 | 未勾「记住」时 token 在 sessionStorage,新标签页需重新登录 |
| 退出为前端行为 | token 无服务端撤销,退出仅清除本地存储 |

## 6. 已知小瑕疵(如实记录)

- `index.html` 默认 title「场馆名录」与页面动态 title「场馆目录」不一致
- `index.html` meta description 仍提及剧院/音乐厅/会展中心等**已删除**的旧类型,与当前四类不符
